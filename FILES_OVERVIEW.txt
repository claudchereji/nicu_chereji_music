CUSTOMIZATION QUICK REFERENCE
================================================================================

EASY CHANGES (Edit HTML/CSS directly)
  - Colors: Edit :root variables in style.css
  - Text: Edit any heading/paragraph in index.html
  - Prices: Change $9.99 or $49.99 in index.html
  - Gradients: Update background-gradient values
  - Add tracks: Copy album-card div and customize

MEDIUM CHANGES (Use commented templates)
  - Album covers: Replace gradients with background-image
  - Add albums: Uncomment album template in HTML
  - Bundles: Use commented createBundleCheckout() in app.js
  - Layout: Adjust grid-template-columns in style.css

ADVANCED CHANGES (Requires new code)
  - Backend: Implement /api/process-order endpoint
  - Emails: Add email service integration
  - Analytics: Add Google Analytics or similar
  - Database: Add customer tracking


DEPLOYMENT STEPS
================================================================================

1. Get PayPal Client ID (5 min)
   - Visit https://developer.paypal.com/dashboard/
   - Create Business account
   - Generate Client ID

2. Add Client ID to index.html (1 min)
   - Find line with: client-id=YOUR_PAYPAL_CLIENT_ID
   - Replace with your actual Client ID

3. Deploy to GitHub (2 min)
   - git add .
   - git commit -m "Add music store"
   - git push origin main

4. Enable GitHub Pages (1 min)
   - Settings → Pages → Source: main branch

LIVE! Your site is now at:
https://yourusername.github.io/nicu_chereji_music/
